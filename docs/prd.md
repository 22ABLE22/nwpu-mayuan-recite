# 马原名词解释背诵应用需求文档

## 1. 应用概述

### 1.1 应用名称
马原名词解释背诵助手

### 1.2 应用描述
基于「马原名词解释.pdf」制作的专业背诵应用，帮助用户高效记忆马克思主义原理课程中的重要名词概念，通过智能化背诵流程管理和学习进度跟踪，提升学习效果。本应用涵盖马原课程中131-180条核心名词解释，共计50个词条。\n
## 2. 核心功能

### 2.1 随机抽题功能
- 从50个精选马原名词解释中随机抽取一个词条展示
- 支持「下一题」按钮切换至新词条

### 2.2 记忆状态标记
- 对每个词条可标记三种状态：\n  - 已背过：掌握熟练的词条
  - 模糊：部分记得但不够熟练
  - 没印象：完全不熟悉的词条

### 2.3 解释查看功能
- 点击词条后跳转至详细解释页面
- 显示完整名词定义和相关内容
- 支持返回继续答题

### 2.4 学习进度管理
- 首页展示学习统计：已背过/模糊/没印象的词条数量
- 支持随时查看各状态下的词条列表
- 提供重新学习功能

### 2.5 流程导航
- 「开始」按钮启动背诵流程
- 「首页」按钮快速返回统计页面

### 2.6 模拟考试功能
- 考试页面布局：6个词条并排展示，顶部显示「请从以下6道题目中任选4道作答」\n- 词条点击交互：点击词条弹出确认框，包含「已背过」选项和关闭按钮
- 状态标记：点击「已背过」后弹窗关闭，词条背景变色；点击关闭按钮弹窗关闭但词条不变色
- 提交逻辑：\n  - 少于4个词条标记「已背过」时弹出确认提示
  - 确认提交后跳转得分页面
  - 取消则不跳转
- 评分规则：\n  - 1题：10分
  - 2题：20分
  - 3题：30分
  - 4题及以上：40分
- 结果展示：\n  - ≥25分：「你真棒」\n  - <25分：「加油」\n- 考试结束后提供「返回主页」和「再试一次」按钮

## 3. 页面结构

### 3.1 首页
- 学习统计展示（已背过/模糊/没印象数量）\n- 「开始背诵」按钮和「模拟考试」按钮并排放置
- 各状态词条查看入口

### 3.2 答题页面
- 随机显示名词词条
- 三种状态标记按钮
- 「下一题」按钮

### 3.3 解释页面
- 词条详细解释内容
- 「返回」按钮

### 3.4 模拟考试页面
- 显示6个随机词条
- 顶部提示「请从以下6道题目中任选4道作答」\n- 底部「提交」按钮
- 词条点击弹窗功能

### 3.5 得分页面
- 显示最终得分和评价语（「你真棒」或「加油」）\n- 「返回主页」和「再试一次」按钮

## 4. 内容清单

### 4.1 词条内容
基于「马原名词解释.pdf」筛选出的131-180条核心名词解释，具体内容如下：\n
**历史任务**：是一定历史事件的主要倡导者、组织领导者或思想理论、科学文化的重要代表人物。\n
**自由**：就人的活动而言，自由表现为人的一种自主力、判断力和选择力，这种自由是相对制约人类行为的必然性而言的，在这个意义上，对必然的认识和世界的改造。\n
**必然王国和自由王国**：必然王国是指人被物化的社会关系支配即受物支配的社会状态；自由王国指人支配自己的社会关系即人支配物的社会状态。\n
**商品经济**：是以交换为目的而进行生产的经济形式，它是一定历史条件下的产物。\n
**自然经济**：是一种以自给自足为特征的经济形式。\n
**社会分工**：指社会劳动划分和独立化为不同的部门和行业。\n
**商品**：是用来交换的能满足人们某种需要的劳动产品，具有使用价值和价值两个因素，是使用价值和价值的矛盾统一体。\n
**具体劳动**：生产一定使用价值的具体形式的劳动，马克思也称为有用劳动。\n
**抽象劳动**：指撇开一切具体形式、无差别的一般人类劳动，即人的体力和脑力的消耗。\n
**劳动的二重性**：任何一种劳动，一方面是特殊的具体劳动，另一方面是一般的抽象劳动。\n
**货币**：是在长期交换过程中形成的固定充当一般等价物的商品。货币具有五种基本职能，即价值尺度，流通手段，贮藏手段，支付手段和世界货币。\n
**价值规律**：商品的价值量由生产商品的社会必要劳动时间决定，商品交换以价值量为基础，按照等价交换的原则进行，形成价值规律。\n
**劳动价值观**：通过对商品关系的深刻分析，马克思阐明了商品的二因素和生产商品的劳动的二重性及其相互关系、价值的质和量的规定性及其变化规律、价值形式的发展和货币的起源、商品经济的基本矛盾和基本规律及其作用所形成的。\n
**资本主义经济制度**：是以资本家占有生产资料和以雇佣劳动为基础的经济制度。\n
**劳动力**：指人的劳动能力，是人的体力和脑力的总和。\n
**生产资料所有制**：经济意义上来说，是指事实上生产资料归谁所有、归谁支配，并凭借这种所有和支配实现生产和获得剩余产品。法律意义上来说，是由占有生产资料的法律原则决定的。\n
**剩余价值**：是雇佣工人所创造的并被资本家无偿占有的超过劳动力价值的那部分价值。\n
**剩余价值规律**：不以人的意志为转移的必然性。\n
**不变资本**：是以生产资料形态存在的资本。\n
**可变资本**：是用来购买劳动力的那部分资本。\n
**绝对剩余价值**：是指在必要劳动时间不变的条件下，由于延长工作日的长度和提高劳动强度而生产的剩余价值。\n
**相对剩余价值**：是指工作日长度不变的条件下，通过缩短必要劳动时间而相对延长剩余劳动时间生产的剩余价值。\n
**资本积累**：把剩余价值转化为资本。或者说，剩余价值的资本化。\n
**资本积聚**：指个别资本通过剩余价值的资本化来增大资本的总量。\n
**资本集中**：指个别资本通过结合而形成较大的资本。\n
**资本循环**：是资本从一种形式出发，经过一系列形式的变化，又回到原来出发点的运动。\n
**资本的周转**：为了不断带来剩余价值而周而复始、不断反复着的资本循环。\n
**平均利润**：按照平均利润率来计算和获得的利润。\n
**平均利润率**：是剩余价值总量对社会总资本的比率。\n
**资本主义的基本矛盾**：生产资料资本主义私人占有和生产社会化之间的矛盾。\n
**生产过剩**：资本主义经济危机的本质特征。但是这种过剩是相对过剩，即相对于劳动人民有支付能力的需求来说社会生产的商品显得过剩，而不是与劳动人民的实际需要相比的绝对过剩。\n
**政党**：是特定阶级利益的集中代表，是代表一定阶级、阶层或集团的根本利益，为达到政治目的，特别是为了取得政权和保持政权而建立的一种政治组织。\n
**两党制**：是由两个势均力敌的政党通过竞选争夺执政地位，交替组织政府，轮流执掌政权的政党制度。\n
**多党制**：指资本主义国家中由两个以上的政党轮流或联合执政的政党制度。\n
**资本主义意识形态**：是在资本主义国家中占统治地位的、反映了作为统治阶级的资产阶级的利益和要求的各种思想理论和观念的总和。\n
**垄断**：指少数资本主义大企业，为了获得高额利润，通过相互协议或联合，对一个或几个部门商品的生产、销售和价格进行操作和控制。\n
**金融资本**：金融资本是由工业垄断资本和银行垄断资本融合在一起而形成的一种垄断资本。\n
**金融寡头**：是指操纵国民经济命脉，并在实际上控制国家政权的少数垄断资本家或者垄断资本家集团。\n
**参与制**：即金融寡头通过掌握一定数量的股票来层层控制企业的制度。\n
**垄断利润**：是垄断资本家凭借其在社会生产和流通中的垄断地位而获得的超过平均利润的高额利润。\n
**国家垄断资本主义**：国家政权和私人垄断资本融合在一起的垄断资本主义。\n
**帝国主义**：即垄断资本主义，是资本主义的垄断阶段，也是资本主义发展的最高阶段和最后阶段。随着生产力的发展和生产社会化程度的提高，资本关系的社会化随之发展，资本主义生产关系发生新的变化，垄断组织的统治成为经济生活的基础，资本主义就从自由竞争阶段进入垄断阶段。\n
**经济全球化**：是指世界经济活动超越国界，通过对外贸易、资本流动、技术转移、提供服务、相互依存、相互联系而形成的全球范围的有机经济整体。经济全球化是当代世界经济的重要特征之一，也是世界经济发展的重要趋势。经济全球化是指贸易、投资、金融、生产等活动的全球化，即生产要素在全球范围内的最佳配置。从根源上说是生产力和国际分工的高度发展，要求进一步跨越民族和国家疆界的产物。\n
**当代资本主义**：主要是指第二次世界大战结束以来西方发达国家的国家垄断资本主义。\n
**国有资本所有制**：指生产资料由国家占有并服务于垄断资本的所有制形式。\n
**法人资本所有制**：是资本主义生产资料所有制发展的形式。\n
**新经济政策**：苏俄在1921年3月开始实行的以发展商品经济为主要特征的向社会主义过渡的经济政策。\n
**无产阶级专政**：无产阶级作为统治阶级掌握国家执政权。\n
**社会主义民主**：社会主义民主是无产阶级和广大人民享有的民主，是绝大多数人的民主。\n
**共产主义社会**：指在生产资料公有制的条件下，在高度发达的社会生产力的基础上，实行各尽所能、按需分配原则的劳动者自由联合的社会经济形态。\n
## 5. 设计风格

### 5.1 配色方案
主色调采用深蓝色（#1E3A8A），辅以橙色（#F97316）作为强调色，背景使用浅灰色（#F8FAFC），营造专业稳重的学习氛围

### 5.2 视觉细节
采用现代卡片式设计，圆角半径8px，添加轻微阴影效果增强层次感，按钮采用渐变色彩和悬停动画

### 5.3 整体布局
采用单页滚动式布局，重要操作按钮固定在页面底部，确保在手机和电脑端都有良好的操作体验
